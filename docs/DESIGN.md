# Pulse 界面方向

Pulse 是可持续查看、可比较节点状态的监控界面。静止时就应有清楚的层次，重复的节点使用相同尺寸和信息顺序。主要通过字号、间距、表面明度和细边界区分信息。

## 参考与取舍

- [shadcn-admin](https://shadcn-admin.netlify.app/)：参考 Dashboard 与 Apps 页的标题、工具栏、网格、辅助文字和控件状态。保留 Pulse 的居中布局与宽屏留白。
- [Aceternity UI](https://ui.aceternity.com/components)：参考 Bento Grid 的区块比例，以及卡片外壳和内容区的关系。概览与地图各自成面板；用于比较的节点保持相同尺寸。
- [RewampUI](https://www.rewampui.com/components)：参考展示区的留白，以及 Folder Tab Card、Chrome Border Button 对底层、边缘和表面的区分。应用为低对比的表面、细边和轻阴影。

这是排版与视觉参考，组件根据实际信息和操作选择。按钮和图标提示复用仓库现有的 shadcn/Radix 组件；节点内容与图表保持适合监控数据的结构。

## 当前规则

- 内容最大宽度 1120px；桌面三列、平板两列、手机单列；宽屏保留两侧留白。
- 概览与平面地图共用一行，面板之间留出 18px。手机保留两列概览指标。
- 工具栏独立成行，分组、搜索和视图切换保持对齐，下面以细线分开节点内容。
- 卡片按身份、资源、网络、辅助信息排列。首页隐藏节点小趋势线，网络指标只用细分隔线组织，状态用卡片边缘的细色轨提示，避免嵌套面板。
- 常规卡片圆角 11px，内部区域 8px，控件约 8px。边框和阴影使用低对比中性色，详情图表保留单一外壳。
- 概览前三项作为主要读数，CPU、内存、磁盘作为次级资源读数；相同指标在各节点的位置一致。
- 流量按节点的实际规则显示：配置周期规则时显示本期用量、额度和比例；没有规则时显示累计上传与下载，不绘制额度条。两种卡片保持等高，概览注明周期统计覆盖的节点数。
- 绿色表示正常与主要操作，红色和琥珀色表示异常或提醒；图表和三网线路保留可区分的系列颜色。
- 悬停轻微改变边界、阴影和入口颜色。键盘焦点始终可见；减少动态效果设置关闭过渡。
- 详情为连续单页，使用返回按钮；图表保持 CPU、内存、磁盘分开及真实缺测断点。
