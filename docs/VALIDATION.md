## 真实面板只读验收

面板地址为 [nezha.daidaiyu.me](https://nezha.daidaiyu.me)，验收时版本为 Nezha V2.6.1。已在浏览器中完成同源登录并读取以下状态：

- `/api/v1/setting` 返回 V2.6.1，`tsdb_enabled` 为 `false`。
- 当前登录账号的 `/api/v1/profile` 返回管理员角色（官方 V2.6.1 中 `role: 0` 为管理员）。
- 管理后台“服务器”表显示“没有内容”；同源 `/api/v1/server` 返回 HTTP 200，但响应没有 `data` 节点；前台 WebSocket 消息只有 `now` 和在线用户计数，没有 `servers` 数组。
- 登录前访客视角同样没有可见节点。由于管理员列表也是空的，当前首页为空不能归因于访客隐藏设置；更可能是该面板实例尚未注册节点，或当前 Dashboard 使用的实例没有节点数据。
- 登录管理员打开 `/server/1` 能进入主题的权限判定，并显示“节点不存在，或当前账号无权查看”，没有伪造详情数据。

因此本轮可以确认登录链路、空节点处理和主题同源接口接入；真实 CPU、内存、磁盘、网络延迟、周期计费与浙江三网曲线还需要先在这个面板注册至少一个节点、配置服务监控和周期规则后再验收。没有修改线上设置、创建任务、安装覆盖或重启服务。

## 配置与回退

周期主规则可用 `window.PulsePrimaryCycleIds` 指定，键为服务器 ID，值为 `cycle_transfer_stats` 中的规则 ID。未指定或指定不存在时回退到该节点接口返回的第一条规则。完整安装和回退步骤见根目录 [README.md](../README.md)。
